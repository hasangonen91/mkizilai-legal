# mkizilai-legal

Public legal pages for **mkizilAI** — an AI coding assistant plugin for JetBrains IDEs and VS Code.

## Live pages

- Home: https://hasangonen91.github.io/mkizilai-legal/
- License: https://hasangonen91.github.io/mkizilai-legal/license/
- Privacy Policy: https://hasangonen91.github.io/mkizilai-legal/privacy/

## Contents

- `index.html` — landing page with links
- `license/index.html` — End User License Agreement
- `privacy/index.html` — Privacy Policy
- `style.css` — shared stylesheet
- `mkizilai-license.md` — Markdown source of the license
- `mkizilai-privacy-policy.md` — Markdown source of the privacy policy

Plain HTML and CSS only. No framework, no build step, no dependencies.
Hosted with GitHub Pages from the `main` branch root.
